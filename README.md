# Hibernate Student Management

A hands-on Java project created to practice **Hibernate ORM** concepts through a simple Student Management system.

## 🛠️ Technologies Used

- Java
- Hibernate ORM
- MySQL
- Maven
- Jakarta Persistence API
- IntelliJ IDEA

## 📚 Concepts Practiced

- Hibernate configuration
- SessionFactory and Session
- Transactions
- Entity mapping
- CRUD operations
- HQL
- `@ManyToOne`
- `@OneToMany`
- `@ManyToMany`
- Foreign key relationships
- Join tables
- Dirty checking
- Lazy and Eager fetching
- Cascade operations
- First-level cache
- N+1 query problem
- Fetch Join
